# Rakuten-pay-ux-field-study

Independent field observation of Rakuten Pay's real-world UX — 4 stores around Waseda University + a first-person onboarding test. Conducted in October 2026 as part of my application preparation for Rakuten Payment (Product/Project Manager).

**Author:** Jingshi Xiao — MSc Architecture, Waseda University (expected Sept 2027)

## What's inside

- `Rakuten Pay UX Field Study.md` — the full report: method, 6 findings, proposal table with validation KPIs, next steps.

## One-paragraph summary

An architect's field method (observe → define → design) applied to a payment product. Findings cover: brand visibility failing in advertising noise, ecosystem interception at checkout, QR-code clutter becoming a physical burden for cashiers, placement ergonomics as the difference between good and bad payment UX, and a failed foreign-user onboarding (language lock, card-linking friction). All observations are first-person and honestly labeled as a small-sample study.
